MySQL
sudo apt install mysql-server
Verificar versión: mysql --versión
Lanzar mysql server siempre que se levante la instacion de EC2: sudo systemctl enable mysql

sudo mysql
CREATE DATABASE IF NOT EXISTS db_canopus;
CREATE USER 'canopus'@'localhost' IDENTIFIED BY 'DEFINE_UNA_CONTRASENA_SEGURA';
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, INDEX, DROP, REFERENCES ON db_canopus.* TO 'canopus'@'localhost';
flush privileges;
exit


sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf
bind-address            = 127.0.0.1 -> bind-address            = 0.0.0.0
grabar-salir
sudo cat /etc/mysql/mysql.conf.d/mysqld.cnfsudo

FileZilla

Crear directorio: /home/ubuntu/canopus/ 


------------------------------------

sudo nano /etc/systemd/system/canopus.service
[Unit]
Description=Canopus
After=network.target

[Service]
EnvironmentFile=/etc/canopus/canopus.env
ExecStart=/usr/bin/java -jar /home/ubuntu/canopus/canopus.jar
WorkingDirectory=/home/ubuntu/canopus
User=ubuntu
Restart=no


sudo systemctl enable canopus.service
sudo systemctl start canopus.service

Crear `/etc/canopus/canopus.env` con permisos restringidos (`sudo chmod 600 /etc/canopus/canopus.env`):
APP_JWT_SECRET=GENERAR_Y_GUARDAR_UN_SECRETO_BASE64
DB_USERNAME=canopus
DB_PASSWORD=DEFINIR_LA_CONTRASENA_DEL_USUARIO_MYSQL
